# treypoore.github.io

Personal portfolio for James (Trey) Poore — AI & Marketing.

## Pages
- `index.html` — Home
- `projects.html` — Project case studies with a live GitHub code viewer
- `resume.html` — Web resume + downloadable PDF

## Updating
- **Text:** edit the HTML files directly.
- **Resume PDF:** replace `assets/James_Poore_Resume.pdf`.
- **Which files the code viewer shows:** edit the `data-files` attribute on each `.viewer` in `projects.html`. The viewer pulls files live from the public GitHub API, so the code is always current.
- **Repo names:** each project's `data-repo` and GitHub links in `projects.html`.

Hosted on GitHub Pages.
